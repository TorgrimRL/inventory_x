The notes were rewritten from raw working notes into concise English process documentation. For standups, the notes follow the daily scrum structure by recording what had been done since the previous meeting, what the team planned to do next, and whether blockers were reported.

Unless a blocker was explicitly mentioned in the raw notes, the rewritten note states that no blockers were reported.

The GitHub Project board was normally reviewed and updated during meetings. Board screenshots are included where available. For earlier meetings where no screenshot was captured, the notes state this explicitly.
