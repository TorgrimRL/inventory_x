# Weekly TA reports

This folder contains weekly summaries of pull requests merged into `main`.

The reports were used to keep track of what had been integrated into the main
branch since the previous TA meeting. Before each weekly meeting, the team used
the reports to get an overview of newly merged work and prepare what should be
demonstrated. After the meetings, the reports were also sent to the TA as a
written summary of what had been released, demonstrated, tested, and discussed.

During the TA meetings, the team demonstrated the released functionality on the
deployed version of the system. The TA also tested the system directly and gave
feedback on functionality, usability, priorities, and possible improvements.
Feedback from these sessions was discussed by the team and, when relevant,
turned into new backlog items, tasks, or user stories.

In this way, the weekly reports supported several parts of the development
process:

- release-like testing, by connecting merged work to the deployed version
- system-level testing, by checking that features worked together after merge
- agile feedback, by giving the team a regular review point with an external stakeholder
- backlog refinement, by turning feedback into concrete follow-up work
